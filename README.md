# VideoPromptGenerator
An extension for Chromium-based browsers such as Edge that generates video prompts compatible with Seedance and Kling video sites

How to install:

Download the code as a ZIP file (using the green "<> Code" button).

Unzip the folder.

Open Edge and go to edge://extensions.

Enable Developer mode in the bottom-left corner.

Click Load unpacked and select the folder you just unzipped
